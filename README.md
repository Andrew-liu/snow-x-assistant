# Snow X Assistant

X(Twitter)浏览助手 Chrome 扩展:

- 推文流速:每条推文的浏览/小时,按阈值分平稳 / 上升 / 爆款三档,独立开关。
- 账号标签:粉丝数、粉丝/关注比、质量标签(互关、大V、疑似互粉号、新号、老号、高互动、低活跃),独立开关。
- 标签主题:信号灯、霓虹、糖果、原生文字、终端、极光渐变,流速与账号标签共用。
- 互关清理:在自己的“正在关注”页筛选未回关、全选、批量取关,在弹窗单独的 Tab 里设置。

流速、账号标签、互关清理三个开关互不影响,账号标签内的每一项也能单独开关。

## 工作方式

- `inject.js` 在页面主世界里复制 X 自己已经发出的 GraphQL 响应,不发新请求。
- 某条推文没抓到 GraphQL 数据时,读取页面上已渲染的浏览数兜底,同样不发请求。
- 互关清理通过点击 X 页面自带的“正在关注 → 取消关注”按钮完成,每次间隔可调(默认 1.5 秒加随机抖动),单次最多 100 个,并在按钮变回“关注”后才计为成功。
- 只申请 `storage` 权限,没有 `host_permissions` 和后台脚本。设置保存在 `chrome.storage.local`。

## 安装

1. 打开 `chrome://extensions`,开启“开发者模式”。
2. 点“加载已解压的扩展程序”,选择本目录(或 `dist/` 下解压后的目录)。
3. 打开 x.com 刷新即可。互关清理需打开 `x.com/你的用户名/following`。

## 开发

无构建步骤。纯函数集中在 `lib/parse.js`,X 改版时优先改这里。
