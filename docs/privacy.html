Snow X Assistant 隐私政策

生效日期：2026-10-27 · 适用版本：0.8.0 及以后

概述

Snow X Assistant 是一个只在 x.com 和 twitter.com 上运行的浏览器扩展。它不收集、不上传、不出售任何个人数据，没有开发者自己的服务器，也不包含统计、广告或追踪代码。

扩展会读取哪些数据

在你浏览 x.com 时，扩展会读取 X 页面自己已经加载的数据（X 网页本身发出的 GraphQL 响应），包括账号的粉丝数、关注数、注册时间，以及推文的浏览量、发布时间、正文和视频地址。这些数据只用于在页面上显示标签、流速、AI 文本概率和视频下载按钮，只保存在浏览器内存里，关闭页面即丢弃。

扩展不读取你的密码、Cookie、私信、浏览历史，也不读取 x.com 以外任何网站的内容。

本地存储

扩展用 chrome.storage.local 保存你的设置（各项开关、主题、语言等），以及使用互关清理时最近一小时内的取关时间（只有时间，没有账号信息，用于限制每小时取关数量）。这些数据只存在你本机的浏览器里，开发者无法访问，卸载扩展即全部删除。

网络请求

扩展只在一种情况下主动发出网络请求：当你使用视频下载功能，而页面上没有该推文的视频信息时，扩展会向 X 官方嵌入组件使用的公开接口 cdn.syndication.twimg.com 请求这条推文的公开信息。请求只包含推文 ID，不携带 Cookie 或任何登录凭证。

下载视频时，浏览器会从 X 的视频服务器 video.twimg.com 直接下载文件，保存到你电脑的下载目录。

除此之外，扩展不会向任何其他服务器发送数据。

第三方共享

扩展不与任何第三方共享数据。不出售数据，不用于广告、用户画像、信用评估或任何与扩展功能无关的用途。

视频下载

视频下载功能仅供个人保存和学习使用。视频版权归原作者所有，请遵守 X 服务条款和当地法律，不要转载或用于商业用途。

变更与联系

本政策如有变化，会在此页面更新并修改生效日期。源代码公开在 GitHub，有问题可以在仓库提 Issue，或在 X 上联系 @xueyu1125。

Snow X Assistant Privacy Policy

Effective date: 2026-10-27 · Applies to version 0.8.0 and later

Summary

Snow X Assistant is a browser extension that runs only on x.com and twitter.com. It does not collect, upload or sell any personal data. It has no developer-operated server and contains no analytics, advertising or tracking code.

Data the extension reads

While you browse x.com, the extension reads data that the X web page has already loaded (the GraphQL responses requested by X itself), such as follower and following counts, account creation dates, tweet view counts, post times, tweet text and video URLs. This data is used only to display tags, view velocity, AI-text likelihood and a video download button on the page. It is kept in memory only and discarded when the page is closed.

The extension does not read your passwords, cookies, direct messages or browsing history, and does not read any website other than x.com and twitter.com.

Local storage

The extension uses chrome.storage.local to save your settings (feature toggles, theme, language, etc.) and, when you use following cleanup, the times of unfollows in the last hour (timestamps only, no account information, used to enforce an hourly limit). This data stays in your browser on this device, the developer cannot access it, and it is removed when you uninstall the extension.

Network requests

The extension makes a network request in only one case: when you use video download and the page has no video information for that tweet, it requests the tweet's public information from cdn.syndication.twimg.com, the public endpoint used by X's official embed widget. The request contains only the tweet ID and carries no cookies or credentials.

When you download a video, the browser fetches the file directly from X's video server video.twimg.com and saves it to your downloads folder.

The extension sends no data to any other server.

Third parties

No data is shared with third parties. No data is sold or used for advertising, profiling, credit assessment or any purpose unrelated to the extension's features.

Video download

Video download is intended for personal saving and study only. Video copyright belongs to the original creators. Please follow the X Terms of Service and local laws, and do not repost or use downloaded videos commercially.

Changes and contact

If this policy changes, this page will be updated with a new effective date. The source code is public on GitHub. For questions, open an issue in the repository or contact @xueyu1125 on X.
